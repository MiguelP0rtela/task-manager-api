# Task Manager API

Uma API REST desenvolvida com FastAPI para gestão de tarefas.

## 🚀 Tecnologias

- Python 3.14
- FastAPI
- Uvicorn
- Docker (em breve)
- PostgreSQL (em breve)
- SQLAlchemy (em breve)

## 📁 Estrutura

```text
app/
├── api/
├── core/
├── database/
├── models/
├── routers/
├── schemas/
├── services/
└── utils/
```

## ▶️ Executar

```bash
uvicorn app.main:app --reload
```

Depois abrir:

```
http://127.0.0.1:8000/docs
```
